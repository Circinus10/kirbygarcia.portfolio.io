Taskflow Web App

A web app designed to help manage tasks. Users can create columns of tasks and keep track of them by marking them complete, adding notes, and displaying due dates. The changes made are saved locally, allowing users to close Taskflow and come back to their tasks later. The main challenge of the project was creating the script. Created using HTML, CSS, Javascript, and the Sortable JavaScript Library, which allows users to click and drag objects.

Project Details:
