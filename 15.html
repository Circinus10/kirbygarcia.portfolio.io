Astronaut Sculpture

An astronaut sculpture created using Blender. The challenge with the project was familiarizing myself in 3D sculpting. This is my first Blender project, and so I was unfamiliar with the tools. If I were to do it again, I would properly remesh the bust so I could use texture painting instead of the vertex painting I had used. Below the render shots are some practice sculptures I had made to familarize myself with the sculpting process. Blender was the only program I used for this project.
